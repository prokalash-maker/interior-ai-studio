# Анализ рисков и стратегии их снижения (RISKS_AND_MITIGATIONS.md)

| Риск | Влияние | Вероятность | Стратегия предотвращения и решения |
| :--- | :--- | :--- | :--- |
| **1. Различие подписки Google AI Pro и Gemini API** | Пользователь ожидает, что подписка Google AI Pro автоматически предоставляет бесплатные неограниченные запросы через внешний API | Высокая | В приложении четко разделены потоки: Google OAuth для идентификации пользователя, и настройка Gemini API Key из Google AI Studio. В интерфейсе дано подробное руководство со ссылкой на получение ключа и прозрачное уведомление о тарификации. |
| **2. Дрейф геометрии помещения генеративной моделью** | Генеративные диффузионные модели могут исказить стены, окна или форму мебели относительно Clay Render | Средняя | Реализован режим «Максимальная точность» в Prompt Builder, добавляющий жесткие структурные негативные и позитивные директивы: строгий запрет перемещения проемов, стен и опор, указание использовать рендер как точный геометрический каркас. |
| **3. Превышение лимитов запросов (Rate Limits 429)** | Ошибка генерации при частых запросах | Средняя | Экспоненциальный backoff при повторах, отображение информативного таймера ожидания пользователю, валидация статуса квоты через Health Check. |
| **4. Отсутствие интернет-соединения** | Недоступность облачной генерации | Высокая | Приложение спроектировано для полной автономности работы с локальными проектами, историей и экспортом в офлайн-режиме; генерация четко сигнализирует о необходимости сети только в момент вызова. |
| **5. Безопасность API-ключей и токенов** | Утечка учетных данных в логи или конфигурационные файлы | Высокая | Шифрование чувствительных строк с помощью Windows DPAPI (`safeStorage`). Ключи никогда не записываются в файлы проектов, логи или открытые JSON. |
| **6. Большой размер и разрешение исходных рендеров (4K-8K)** | Медленная загрузка или ошибка по размеру полезной нагрузки (Payload Too Large) | Средняя | Встроенный модуль оптимизации размера перед отправкой в API с сохранением оригинального соотношения сторон и сохранением локального полноразмерного исходника без изменений. |
