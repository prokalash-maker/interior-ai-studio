# AI Designer by V1PERCOREJZ

> Профессиональное Windows desktop-приложение для AI-визуализации интерьеров на основе белых/серых рендеров (Clay Render) из **Graphisoft Archicad** с использованием модели **Google Gemini 3 Pro Image (Nano Banana Pro)**.

---

## 🚀 Быстрый запуск

### 1. Запуск приложения:
```bash
npm start
```
*Приложение мгновенно запустится в нативном окне Windows 10/11.*

### 2. Режим разработки с Hot Reload:
```bash
npm run dev:electron
```

### 3. Полная пересборка:
```bash
npm run build
```

## 🎨 Основной рабочий процесс (Workflow)

1. **Экспорт из Archicad**: В 3D-окне Archicad выберите нужный ракурс и сделайте предварительный рендер белой модели (Clay Render). Экспортируйте в PNG или JPG.
2. **Загрузка**: Откройте **AI Designer by V1PERCOREJZ** и перетащите рендер в рабочую область (или воспользуйтесь встроенным примером Archicad Clay Render).
3. **Настройки**:
   - Выберите тип помещения (Гостиная, Кухня, Спальня и др.).
   - Выберите стиль интерьера из библиотеки (19 профессиональных стилей: Modern, Japandi, Wabi-Sabi, Neoclassic, Loft и др.).
   - Выберите режим приоритета геометрии, чтобы попросить модель бережнее отнестись к стенам и мебели Archicad; генеративная модель всё равно может изменить детали.
   - Задайте сценарий освещения и предпочтительные материалы.
4. **Prompt**: Проверьте автоматически сгенерированный профессиональный запрос (или отредактируйте его вручную).
5. **Генерация**: Нажмите **«Сгенерировать в Nano Banana Pro»**.
6. **Сравнение**: Используйте интерактивный бегунок (Split-Screen Slider) для сравнения исходного Clay Render и готовой визуализации.
7. **Уточнение**: Введите дополнительную текстовую правку (например: *«Сделай свет теплее и замени фасады на дуб»*) для многоходового редактирования.
8. **Экспорт**: Сохраните результат в PNG/JPG или скопируйте в буфер обмена.

## 🔑 Подключение Nano Banana Pro (Google Gemini API)

1. Перейдите в **Настройки → AI-провайдеры → Google Gemini**.
2. Вставьте ваш API-ключ, созданный в [Google AI Studio](https://aistudio.google.com/app/apikey).
3. Выберите модель: `gemini-3-pro-image` (Nano Banana Pro).
4. Нажмите **«Проверить соединение»**.
5. Нажмите **«Сохранить»**. Ключ надежно зашифрован средствами Windows DPAPI.

*Обратите внимание: запросы через API тарифицируются отдельно от потребительской подписки Google AI Pro в соответствии с квотами Google AI Studio.*

## 📁 Структура проекта и документация

- `CODEX_INSTRUCTIONS.md` — актуальный курс продукта и правила дальнейшей разработки.
- `HANDOVER_FOR_CODEX.md` — цели продукта, требования пользователя, архитектурный контекст и состояние функций.
- `ANTIGRAVITY_HANDOFF.md` — подробный журнал выполненных изменений, сборок, проверок и открытых задач.
- `DEVELOPMENT_ROADMAP_V2.5.md` — приоритеты дальнейшей разработки и критерии приёмки.
- `PROMPT_FOR_ANTIGRAVITY.md` — готовый промт, с которого Antigravity должен начать изучение проекта.
- `PROJECT_PLAN.md` — подробный план разработки и этапы реализации.
- `TECHNICAL_ARCHITECTURE.md` — архитектурная схема, слой AI-провайдеров, схема SQLite, безопасность.
- `ARCHICAD_INTEGRATION.md` — концепция и дорожная карта интеграции с Archicad (включая будущий C++ Add-on).
- `RISKS_AND_MITIGATIONS.md` — матрица рисков и стратегии их предотвращения.
- `electron/` — системный процесс Electron (окно, Windows DPAPI, loopback OAuth, нативные диалоги).
- `src/` — компонентная архитектура React 19 + TypeScript + Tailwind CSS:
  - `services/ai/GeminiProvider.ts` — интеграция Google Gemini 3 Pro Image (Nano Banana Pro).
  - `services/promptBuilder.ts` — генератор архитектурных промптов и библиотеки стилей.
  - `components/ImageComparisonSlider.tsx` — интерактивный бегунок Before/After.
  - `views/GenerationStudioView.tsx` — главное рабочее пространство студии.

## Текущий фокус интерфейса

Основной workflow остаётся в Studio. В главном меню доступны Gemini Bridge, проекты, история, LoRA Studio и настройки; AI-апскейлер находится в верхней панели. Для генерации отображаются ComfyUI, Gemini API и Gemini Bridge. Каталог/тренды и отдельная библиотека стилей убраны из навигации, при этом выбор стиля в Studio сохранён.

## Вход Google

В «Настройки → Google Аккаунт» можно указать OAuth Client ID типа Desktop application из Google Cloud Console. Студия открывает системный браузер, получает подтверждённый профиль через OAuth 2.0 PKCE и хранит токены в зашифрованном хранилище главного процесса Electron. Локальный профиль не считается входом в Google.

Gemini Bridge открывает Gemini Web в обычном браузере для входа в личный Google-аккаунт. Результат из этого браузера скачивается пользователем и импортируется в Bridge; встроенное окно предназначено для уже действующей сессии. Вход в студию не создаёт сессию Gemini Web и не заменяет API-ключ Gemini.
