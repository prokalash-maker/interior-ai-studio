# AI Designer by V1PERCOREJZ

Настольное приложение для визуализации интерьеров по белым и серым рендерам из Archicad и других 3D-редакторов.

## Быстрый запуск

Если сборка и Electron уже есть в папке проекта, дважды нажмите **Start Visual AI.cmd**.

Для работы с исходниками установите [Node.js LTS](https://nodejs.org/en/download), откройте новый терминал в папке проекта и выполните команды.

```powershell
npm ci
npm run build
npm start
```

Для разработки используйте `npm run dev:electron`.

## Gemini Bridge и Google Flow

1. Загрузите исходный рендер.
2. Выберите помещение, стиль и свет. В «Материалах по артикулам» есть стартовые позиции Intercerama / INTER GRES, Swisspan и Kronospan. Можно добавить свой артикул и фото образца, задать раскладку и скачать ведомость CSV. В «Разметке зон» обведите нужные участки на исходнике.
3. Откройте Gemini. Bridge скопирует изображение. Вставьте его в поле сообщения, вернитесь за готовым текстом, вставьте текст и отправьте запрос. Войдите на сайте Gemini, если браузер запросит вход.
4. Скачайте изображение в Gemini. Bridge предложит свежие файлы со стандартными именами Gemini из папки «Загрузки». При другом имени или папке выберите файл вручную, перетащите его или вставьте скопированное изображение.
5. Сравните результат с исходником, сохраните копию, подготовьте доработку или утвердите дизайн для остальных ракурсов. Импортированные результаты доступны в истории.

Перед сохранением Bridge покажет исходник, выбранное изображение, его размер и целевой ракурс. На шаге «Результат» скопированную картинку можно вставить клавишами Ctrl+V.

Можно подготовить запросы для нескольких ракурсов и продолжить после перезапуска. В списке исходников выберите нужный ракурс и нажмите «Продолжить запрос». Для параллельных запросов в Gemini выберите скачанный файл вручную, чтобы связать его с нужным ракурсом.

Чтобы использовать **Google Flow**, на шаге «Генерация» нажмите «Открыть Google Flow». Bridge подготовит папку с исходником, утверждённым референсом, листом образцов, разметкой и текстом запроса в зависимости от настроек ракурса. Добавьте изображения в проект Flow, вставьте запрос, выберите режим изображения и запустите генерацию. Скачанные результаты можно импортировать по одному как варианты того же ракурса. Для обоих веб-маршрутов действуют лимиты Google-аккаунта.

**FLUX.2 Klein 4B** доступен на том же шаге как резервный маршрут. Он открывает официальное демо Black Forest Labs на Hugging Face. Используйте тот же комплект и импортируйте результат после генерации. У демо есть очередь и бесплатная квота ZeroGPU.

## Облачный апскейл

«Увеличить до 2K в Flow» доступно рядом с результатом. Используйте увеличение в интерфейсе Flow и импортируйте скачанный файл. Google указывает дневной лимит на 2K без подписки AI.

В основных настройках подключите [аккаунт Cloudinary](https://console.cloudinary.com/) с помощью Cloud name, API key и API secret. Бесплатный тариф включает 25 кредитов в месяц. Ключ хранится в защищённом хранилище приложения.

После импорта результата откройте «Облачный апскейл» и нажмите «Увеличить изображение». Cloudinary принимает изображения до 4,2 Мп и 10 МБ для этого сценария. Результат увеличивается до 4 раз с ограничением 25 Мп. Приложение загружает увеличенную копию и запрашивает удаление временного облачного файла.

## Кеш приложения

В разделе «Настройки → Кеш приложения» можно проверить объём временных файлов, очистить кеш встроенного браузера и Bridge или открыть папку данных. Проекты, настройки и авторизация сохраняются.

## Экспертный режим

Включите «Настройки → Экспертный режим и локальный ИИ», чтобы открыть студию генерации, ComfyUI, LoRA и расширенные настройки. Приложение запоминает выбранный режим.

## 📁 Структура проекта и документация

- `CODEX_INSTRUCTIONS.md` — актуальный курс продукта и правила дальнейшей разработки.
- `HANDOVER_FOR_CODEX.md` — цели продукта, требования пользователя, архитектурный контекст и состояние функций.
- `ANTIGRAVITY_HANDOFF.md` — подробный журнал выполненных изменений, сборок, проверок и открытых задач.
- `DEVELOPMENT_ROADMAP_V2.5.md` — приоритеты дальнейшей разработки и критерии приёмки.
- `PROMPT_FOR_ANTIGRAVITY.md` — готовый промт, с которого Antigravity должен начать изучение проекта.
- `PROJECT_PLAN.md` — подробный план разработки и этапы реализации.
- `TECHNICAL_ARCHITECTURE.md` — архитектурная схема, слой AI-провайдеров, схема SQLite, безопасность.
- `ARCHICAD_INTEGRATION.md` — концепция и дорожная карта интеграции с Archicad (включая будущий C++ Add-on).
- `RISKS_AND_MITIGATIONS.md` — матрица рисков и стратегии их предотвращения.
- `electron/` — системный процесс Electron (окно, Windows DPAPI, loopback OAuth, нативные диалоги).
- `src/` — компонентная архитектура React 19 + TypeScript + Tailwind CSS:
  - `services/ai/GeminiProvider.ts` — интеграция Google Gemini 3 Pro Image (Nano Banana Pro).
  - `services/promptBuilder.ts` — генератор архитектурных промптов и библиотеки стилей.
  - `components/ImageComparisonSlider.tsx` — интерактивный бегунок Before/After.
  - `views/GenerationStudioView.tsx` — главное рабочее пространство студии.
