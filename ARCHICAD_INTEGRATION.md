# Архитектура и стратегия интеграции с Graphisoft Archicad (ARCHICAD_INTEGRATION.md)

## 1. Концепция взаимодействия с Archicad
Архитекторы и дизайнеры интерьеров создают трехмерные BIM-модели помещений в **Graphisoft Archicad** (версии 23, 24, 25, 26, 27 и новее), настраивают геометрию, перегородки, оконные и дверные заполнения, расстановку мебели из каталогов GDL-библиотек и светильники.

Основной рабочий процесс с **INTERIOR AI STUDIO**:
1. В Archicad настраивается перспектива или аксонометрия 3D-окна.
2. В параметрах визуализации выбирается базовый механизм рендеринга (Basic Render Engine) или рендер белой модели (Clay / White Model Render).
3. Экспортируется четкий геометрический рендер в формате PNG или JPG.
4. Изображение загружается в **INTERIOR AI STUDIO**.
5. На основе анализа геометрии и текстового описания модель **Nano Banana Pro (`gemini-3-pro-image`)** накладывает физически корректные материалы, текстуры, объемное освещение и тени, не нарушая пропорций и расположения стен.

## 2. Фазы интеграции

### Фаза 1 (Текущая реализация — V1):
- **Файловый импорт**: Поддержка прямого Drag & Drop и файлового выбора экспортированных из Archicad рендеров.
- **Поддержка метаданных ракурсов**: Возможность сохранения имени камеры, угла обзора (FOV) и ориентации.
- **Экспорт в рабочую папку проекта Archicad**: Быстрое сохранение сгенерированных финалов в каталог рядом с исходным `.pln` файлом.
- **Отдельная папка для технических проходов**: Подготовка структуры проекта для мульти-слотов:
  - `Base Clay Render` (Основной белый рендер)
  - `Lineart / Wireframe` (Линейный чертеж 3D-окна Archicad)
  - `Depth Pass` (Карта глубины)
  - `Material ID / Surface Pass` (Проход цветовых идентификаторов материалов)

### Фаза 2 (Протокол межпроцессного обмена — CLI & Deep Link):
- Регистрация в Windows кастомного URL-протокола `interior-ai://import?file=...&project=...`
- Запуск приложения из командной строки Archicad Publisher с флагами передачи рендера:
  ```bash
  InteriorAIStudio.exe --import "C:\Projects\Apartment\ClayRender_Living.png" --room "living_room" --style "modern"
  ```
- Папка автонаблюдения (Watch Folder): автоматический захват новых изображений, попадающих в выделенный каталог экспорта Archicad.

### Фаза 3 (Полноценный нативный Archicad Add-On):
- Разработка плагина на C++ с использованием **Graphisoft Archicad API Development Kit (APIDK)**.
- Добавление отдельного пункта меню в Archicad: `Интерьер → Отправить в Interior AI Studio`.
- Прямой экспорт активного 3D-вида и автоматический возврат сгенерированного изображения в качестве текстуры или рендера в Архикад-макет (Layout Book).
- Совместимость с Archicad 23–27+ за счет абстракции API Graphisoft.

## 3. Рекомендации архитектору по настройке рендера в Archicad для максимального качества AI
1. **Режим отображения**: Рекомендуется использовать 3D-окно Archicad в режиме «Векторный механизм» или «Аппаратное ускорение» с чистыми белыми/нейтрально-серыми поверхностями (Clay Render).
2. **Освещение**: Включить мягкое солнечное освещение под углом 45° к оконным проемам для четкого чтения светотеневого рисунка объема помещения.
3. **Разрешение**: Для наилучшего результата отправлять рендеры с разрешением от `1920x1080` (Full HD) до `3840x2160` (4K) без искажений пропорций.
4. **Контрастность**: Избегать абсолютно черных провалов в тенях, чтобы AI мог распознать предметы мебели в угловых зонах.
