## 1. Введение и цели проекта
**INTERIOR AI STUDIO** — специализированное настольное приложение (Windows 10/11) для профессиональных архитекторов и дизайнеров интерьера.
Основная цель: преобразование белых/серых предварительных рендеров (Clay Render), экспортированных из **Graphisoft Archicad** (или других САПР/3D-пакетов), в высокореалистичные интерьерные визуализации фотографического качества с использованием модели **Google Gemini 3 Pro Image (Nano Banana Pro)** с сохранением геометрии, стен, проёмов и расстановки мебели.

---

## 2. Команда Agency Agents и распределение ответственности
В проекте задействованы специализированные роли из каталога Agency Agents:
- **Agents Orchestrator**: сквозное управление этапами разработки, непрерывный цикл Dev ↔ QA, соблюдение критериев качества.
- **Architect UX & UI Designer**: дизайн-система студийного уровня, темная графитовая тема, микро-взаимодействия, сравнение до/после.
- **Backend Architect**: архитектура локального хранилища SQLite, файловый репозиторий проектов, безопасное хранение учетных данных.
- **AI Engineer & API Developer**: реализация слоя AI-провайдеров, контракт Gemini 3 Pro Image (`gemini-3-pro-image`), потоковая передача, многоходовое редактирование (Multi-turn chat).
- **AppSec Engineer**: безопасность OAuth 2.0 (PKCE, loopback server), шифрование токенов через Windows DPAPI (`safeStorage`), изоляция IPC, отсутствие утечек API-ключей в логи.
- **Testing & Reality Checker**: бескомпромиссная верификация всех пользовательских сценариев перед маркировкой этапа выполненным.

Точная проекция текстур как в 3ds Max/Artlantis потребует доступа к 3D-модели/UV-развёртке или отдельного CAD/3D-пайплайна.
